## 为什么开始做 Linkozen？

作为一个独立开发者，我一直在寻找一个既能够自由发挥技术想法，又能够真正帮助到普通用户的方向。安全与隐私工具是一个天然的选择——它们不需要昂贵的后端基础设施，可以在浏览器中完全运行，而且**每个人都有权利免费使用它们**。

### 核心理念

Linkozen 的三个基本原则：

1. **纯客户端计算** — 所有工具必须在浏览器中运行，不需要服务器
2. **零数据上传** — 用户的数据永远不会离开设备，我们不收集、不存储、不追踪
3. **开源透明** — 每一行代码都可以被审查，没有任何隐藏逻辑

### 为什么是工具站？

市面上的在线工具要么充斥着广告和追踪，要么需要付费订阅。我想做一个**干净、快速、免费**的替代方案——没有广告追踪、没有数据收集、没有付费墙。

## 技术选型

### 为什么选原生 HTML + Tailwind CDN？

- **零构建步骤**：不需要 Webpack、Vite 或任何打包工具
- **即时部署**：修改 HTML 文件后直接推送到 Cloudflare，无需构建
- **极致的性能**：Tailwind CDN 只加载页面实际使用的 CSS 类
- **简单维护**：每个页面都是一个独立文件，修改一个工具不会影响其他工具

### Cloudflare 架构

整个站点运行在 Cloudflare 的免费层级上：
- **Cloudflare Pages** — 静态文件托管
- **Cloudflare Workers** — 处理需要服务端的 API 请求（如 IP 检测、货币汇率代理）
- **GitHub Actions** — 自动部署

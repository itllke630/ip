Which Icon Sizes Do You Need?

🌐 Web / Favicon

16×16 — Classic browser tab favicon. Required for all websites. Displayed in browser tabs, bookmarks, and history.

32×32 — Higher-DPI browser tabs and bookmark bars. Recommended as a minimum for modern displays.

48×48 — Windows taskbar pinning and desktop shortcuts from browsers. Often used by CMS platforms like WordPress.

💡 Tip: Select 16 + 32 + 48 together for a complete favicon package. Modern browsers will pick the best size automatically.

🖥️ Desktop Applications

16×16 — Windows system tray icons, small icon view in Explorer, and window title bar icons.

32×32 — Standard Windows desktop and Explorer icon size. Required by most installers.

48×48 — Windows medium icons and Linux desktop entries. Good default for cross-platform apps.

64×64 — macOS dock icons (small) and high-DPI Linux desktop environments. Also used in Windows large icon view.

128×128 — macOS dock icons (large / Retina) and Windows large thumbnails. Recommended for modern desktop apps.

📱 PWA & Mobile

48×48 — Android Chrome PWA icons (mdpi). Minimum for a Progressive Web App manifest.

128×128 — iOS home screen icons and Android (xhdpi). The most common PWA icon size for modern devices.

💡 Note: For full PWA support, you'll also need a 192×192 and 512×512 PNG. This ICO tool covers the favicon side — use the Image Converter tool for larger PWA icons.

⚡ Quick Reference

For websites: 16 + 32 + 48
For Windows apps: 16 + 32 + 48 + 64
For macOS apps: 64 + 128
For PWA: 48 + 128
Full coverage: 16 + 32 + 48 + 64 + 128
